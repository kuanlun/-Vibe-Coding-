# 盲盒展示网页 - 需求文档

## 1. 项目概述

**项目名称**: 盲盒展示网页
**项目类型**: 前后端分离的Web应用
**核心功能**: 精美展示盲盒商品图片和基本信息，支持后台管理
**部署方式**: 本地运行测试，后续部署到服务器

---

## 2. 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | HTML/CSS/JavaScript | 原生前端，轻量易维护 |
| 后端 | Python | 处理业务逻辑和API |
| 数据库 | SQLite | 轻量级数据库，适合本地和小型部署 |

---

## 3. 功能需求

### 3.1 前端展示页面

- **首页**: 展示所有盲盒商品列表
- **详情页**: 展示单个盲盒的详细信息（图片、名称、描述、价格等）
- **响应式设计**: 适配电脑和手机浏览器

### 3.2 后台管理系统

- **登录验证**: 管理员账号登录
- **盲盒管理**: 添加、编辑、删除盲盒商品
- **图片上传**: 上传盲盒封面图片到本地
- **数据列表**: 分页展示和管理盲盒数据

### 3.3 界面风格

**简约小清新风格**:
- 马卡龙色系配色
- 圆角设计
- 柔和阴影效果
- 简洁留白布局
- 清爽的用户体验

---

## 4. 数据模型

### 盲盒商品 (BlindBox)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| name | TEXT | 盲盒名称 |
| description | TEXT | 描述信息 |
| price | REAL | 价格 |
| image_path | TEXT | 本地图片路径 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 管理员 (Admin)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| username | TEXT | 用户名 |
| password | TEXT | 密码（加密存储） |

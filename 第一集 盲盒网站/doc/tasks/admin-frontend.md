## 概述
- 职责: 管理员盲盒管理界面
- 依赖: backend-api.md, database.md
- 完成标准: 管理员可完整管理盲盒

## 子任务

### HTML页面
- [ ] `templates/admin/login.html` - 登录页

- [ ] `templates/admin/list.html` - 盲盒列表页
- [ ] `templates/admin/form.html` - 新增/编辑表单

### 功能清单
- [ ] 登录验证 (用户名/密码)
- [ ] 盲盒列表 (分页展示)

- [ ] 登出功能

# 股票仓库监控网站 - 需求文档

## 1. 项目概述

- **项目名称**：Stock Portfolio Monitor（股票仓库监控）
- **项目类型**：Web 监控平台
- **核心功能**：多市场股票持仓监控，支持 A股、台股、美股，实时数据展示，价格提醒
- **目标用户**：个人投资者/小团队（不超过10人）

## 2. 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 后端 | Python (FastAPI) | 高性能 API 框架 |
| 前端 | Vue 3 + Vite | 主流、易维护 |
| 数据库 | SQLite | 轻量级，满足需求 |
| 数据源 | 免费 API | Yahoo Finance / AKShare / 富途 API |
| 部署 | 腾讯云服务器 | Linux 环境 |

## 3. 功能需求

### 3.1 用户系统
- 用户注册/登录（JWT 认证）
- 用户个性化设置
- 多用户支持（上限10人）

### 3.2 持仓管理
- 添加/编辑/删除持仓股票
- 支持多市场：A股、台股、美股
- 显示：持仓数量、买入价格、成本
- 按市场分类展示

### 3.3 数据展示
- **核心指标**：当前价、涨跌幅、持仓盈亏、成交量
- **界面风格**：深色 Linear 风格
- **布局**：按市场分类，每个市场一个卡片/区块
- **响应式**：支持桌面端 + 移动端

### 3.4 提醒功能
- 价格提醒（高于/低于阈值）
- 提醒渠道：应用内通知、邮件、微信
- 用户可开关每种提醒方式

### 3.5 数据刷新
- 首次加载获取全量数据
- 定时轮询（降低 API 调用频率）
- 缓存机制减少请求

### 3.6 货币转换
- 美股/台股收益换算人民币
- 使用免费汇率 API

## 4. 非功能需求

- **性能**：页面加载 < 3秒
- **可用性**：移动端适配
- **安全**：用户数据隔离，密码加密
- **维护**：代码结构清晰，易于扩展

## 5. 数据源 API

| 市场 | 推荐 API | 说明 |
|------|----------|------|
| A股 | AKShare | 免费，Python 生态 |
| 美股 | Yahoo Finance | 免费，REST API |
| 台股 | AKShare / 富途 | 免费/付费 |
| 汇率 | exchangerate-api | 免费 API |

## 6. 页面结构

```
├── 登录/注册页
├── 主页（仪表盘）
│   ├── A股持仓卡片
│   ├── 台股持仓卡片
│   └── 美股持仓卡片
├── 持仓管理页（增删改股票）
├── 个人设置页（提醒偏好）
└── 通知中心
```
